# SWYNEX Technologies – Task 1: Data Cleaning and Preparation

## Project Overview
This project was completed as part of my internship at SWYNEX Technologies.

The objective of this task was to understand a supermarket sales dataset and prepare it for further analysis using Microsoft Excel.

## Dataset Description
The dataset contains supermarket sales information, including:
- Invoice ID
- Branch and City
- Customer Type and Gender
- Product Line
- Unit Price and Quantity
- Tax and Total Sales
- Date and Time
- Payment Method
- Cost of Goods Sold (COGS)
- Gross Income
- Customer Rating

## Tool Used
- Microsoft Excel

## Data Cleaning and Preparation
The dataset was reviewed for data quality issues and prepared for analysis.

Document the specific operations performed, such as:
- Checking for missing values
- Checking duplicate records
- Reviewing date and number formats
- Verifying sales and tax calculations
- Checking consistency in the data

## Outcome
This task helped me gain practical experience working with spreadsheet data and understand the importance of data quality in Data Analytics.
